## 🚀 About Me

I'm an **Applied AI Engineer** focused on building production AI systems using **Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), NLP, and MLOps infrastructure**.

I have 3+ years of experience delivering machine learning solutions across **insurance and fintech**, building systems that automate complex workflows, process large-scale documents, and transform business operations using AI.

My work includes:

- 🤖 Building LLM-powered applications using RAG, fine-tuning (LoRA/PEFT), LangChain, LangGraph, and MCP architectures.
- 📄 Developing document intelligence systems for insurance workflows using OCR, embeddings, vector search, and LLM reasoning.
- ⚙️ Designing scalable ML pipelines with DVC, MLflow, Airflow, Docker, Kubernetes, and cloud infrastructure.
- 💳 Building fraud detection and financial ML systems using PySpark, Kafka, and ensemble machine learning models.
- 🌏 Developing NLP tooling for low-resource languages, including HimalayanTokenizer — a Nepali-focused tokenizer for LLM applications.

Previously, I worked as an Applied AI/ML Engineer at **EXL**, building AI solutions for insurance automation and enterprise workflows.

Currently exploring:
- Efficient tokenization for multilingual LLMs
- Small language models and transformer architectures
- Agentic AI workflows
- Production-grade AI infrastructure
